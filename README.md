# void-minigames

CoC 模组《VOID》的外置小游戏。网页形式，电脑和手机都能玩，用来在部分剧情节点代替骰子判定。

## 目录

```
games/
  hack/          弹幕骇入（拘留所骇入；之后也用于 50 层全息投影、门禁锁、骇入鸣宫）
    index.html   单个文件，直接用浏览器打开即可
docs/
  设计计划.md    全部小游戏的设计计划、剧情位置、开发顺序
```

## 本地试玩

下载 `games/hack/index.html`，用浏览器打开。
