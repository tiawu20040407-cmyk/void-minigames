# 录像排序 · 替换图片需求（给画师）

## 尺寸与格式

- **画面图片尺寸一样：640 × 480 像素（4:3）**，PNG。想画像素风，可以画成 160 × 120，再整数倍放大到 640 × 480 交稿。
- **贴图也画成 640 × 480 的整张透明 PNG**，物件直接画在它该在的位置。这样和背景叠在一起就对齐了，不用另外标坐标。
- 正常彩色画就行，白天光线。监控的灰绿滤镜、噪点、时间戳、雨丝、早晚光线都由游戏加，**不要画时间戳和边框**。
- 画面会缩成缩略图（约 160 × 120），所以物件要大、轮廓清楚：**每个线索物件至少占画面宽度的 1/10**。
- 一羽 Q 版：**256 × 256 透明 PNG**。

## 一、公寓门口（正式关卡）

摄像头装在走廊天花板角落，从斜上方往下拍一扇公寓房门和门前一小段外走廊（日式公寓的室外走廊，栏杆外能看到天空）。2050 年近未来，但公寓很普通。门是刷卡的自动锁门，门边有读卡面板，**门前有一块地垫**。

| 文件名 | 类型 | 内容 |
|---|---|---|
| `bg_sunny.png` | 背景 | 晴天。地面干燥，栏杆和柱子在地上有**清楚的影子**。 |
| `bg_rain.png` | 背景 | 雨天。地面湿、有两三个**水洼**，没有影子。构图和晴天那张完全一样，只换天气。雨丝不用画。 |
| `umbrella.png` | 贴图 | 门口地上**撑开晾着一把黑伞**，伞下一摊积水。伞要**纯黑、带一点亮边**（游戏不会给它加滤镜，它会在灰绿画面里很突出）。 |
| `newspaper.png` | 贴图 | 门边地上**堆着一整摞报纸**，用绳子捆着，旁边散落一份。看起来是好几天没人收。 |
| `cat.png` | 贴图 | 一只**白猫**蹲在门前的地垫上。 |
| `hood_pick.png` | 贴图 | 穿黑色连帽衫、戴兜帽的人，背对或侧对镜头，蹲在门边摆弄读卡器。看不到脸。 |
| `hood_leave.png` | 贴图 | 同一个人，从门口走向画面边缘离开。看不到脸。 |
| `blue_drops.png` | 贴图 | 那个人走过的地上几滴**亮蓝色**液体，小但要看得见。游戏不给它加滤镜。 |

性格：喜欢扮可爱，想到什么说什么，略带毒舌。

## 放到哪里

画好的图放进 `games/footage/assets/` 文件夹，文件名用上表的名字。游戏打开时自动读取，缺哪张就用哪张的占位图。

## 注意

- 两张公寓背景的构图、角度、门和地垫的位置必须一致，贴图叠在两张上都要对得上。
- 黑兜帽人两张身材、衣服要一致。
- 办公室日历的位置如果和占位图不同，告诉开发者改 `CONFIG.calBox`（日历页在画面里的范围）；蓝色液体的位置不同则改 `CONFIG.dropsBox`。
