# 录像排序 · 替换图片需求（给画师）

## 画的是什么

公寓门口的监控录像截图。摄像头装在走廊天花板角落，从斜上方往下拍一扇公寓房门和门前一小段外走廊（日式公寓的室外走廊，栏杆外能看到天空，所以下雨时看得出来）。

时间设定 2050 年，近未来，但公寓很普通，不需要科幻元素。门是刷卡的自动锁门，门边有一个读卡面板。

## 尺寸与格式

- **所有图片尺寸一样：640 × 480 像素（4:3）**，PNG。
- 想画像素风的话，可以画成 160 × 120，再整数倍放大到 640 × 480 交稿。
- **贴图也画成 640 × 480 的整张透明 PNG**，物件直接画在它在门口该在的位置。这样和背景叠在一起就对齐了，不用另外标坐标。
- 正常彩色画就行，白天光线。监控的灰绿滤镜、噪点、时间戳、早晚光线变化都由游戏加，**不要画时间戳和边框**。
- 画面会被缩小成缩略图（约 160 × 120 显示），所以物件要大、轮廓清楚，细节不重要。

## 清单（共 8 张）

| 文件名 | 类型 | 内容 |
|---|---|---|
| `bg_sunny.png` | 背景 | 晴天。地面干燥，栏杆和门框在地上有**清楚的影子**。 |
| `bg_rain.png` | 背景 | 雨天。地面湿、有两三个**水洼**，没有影子。构图和晴天那张完全一样，只换天气。雨丝由游戏加，不用画。 |
| `umbrella.png` | 贴图 | 门边靠墙立着一把湿的长柄伞，地上有一小摊水。 |
| `newspaper.png` | 贴图 | 门前地上放着一份卷起来或叠好的报纸。 |
| `cat.png` | 贴图 | 一只流浪猫，坐在或走在走廊上，靠近画面边缘。 |
| `hood_pick.png` | 贴图 | 穿黑色连帽衫、戴兜帽的人，背对或侧对镜头，蹲在门前撬锁。看不到脸。 |
| `hood_leave.png` | 贴图 | 同一个人，从门口走向画面边缘离开。看不到脸。 |
| `blue_drops.png` | 贴图 | 门口地上几滴**亮蓝色**液体，小但要看得见。 |

## 注意

- 两张背景的构图、角度、门的位置必须一致，贴图叠在两张上都要对得上。
- 黑兜帽人两张身材、衣服要一致。
- 蓝色液体是重要线索，颜色要和画面其他东西明显不同。
