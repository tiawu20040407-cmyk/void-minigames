# VOID 外置小游戏 设计计划

> 状态：粗略计划已确定（2026-11-24）。按开发顺序逐个制作，每个游戏做 demo 前需 KP 确认。

---

## 一、总体原则

- **小游戏结果直接取代骰子**，PC 的技能值决定游戏难度。
- **结果分级**：完美通关 = 极限成功（额外信息）；通关 = 成功；失败 = 原文失败分支。
- **只替换值得替换的判定**：查数据库这类一句话出结果的检定继续投骰。
- **剧透控制必须做**：秘密内容只推送给对应玩家。
- **双端兼容**：电脑和手机都能玩。
- **跑团形式**：线上，QQ 文字 + 骰子。游戏以网页链接形式发给玩家，建议用系统浏览器打开（QQ 内置浏览器兼容性较差）。
- **UI 先做简单的**：尼尔式黑白线框基础风格，外观集中在可编辑的样式层，之后可在编辑器里改。

### 弹幕引擎进度（2026-11-24）

- 单机版完成，文件 `games/hack/index.html`（仓库 tiawu20040407-cmyk/void-minigames）。
- 结构：引擎（对象池、预渲染精灵、批量绘制）+ 敌人零件 + 关卡配置。新场景只需写新的关卡配置。
- 敌人零件：防火墙、核心（护盾）、射手、突袭（冲刺+预警线）、扫描器（激光，预警线即实际位置）、守卫程序 Boss（三阶段）。
- 关卡：防火墙（75 秒）、数据流（三波小怪+扫描器，70 秒）、守卫程序（Boss，90 秒）、随机。
- 难度三档：一档 1.3 / 二档 1.4 / 三档 1.6，由 KP 设定。
- 操控：跟手（默认）/ 摇杆，可调灵敏度。
- 性能：像素比上限 2；卡顿 1.5 秒自动切换简化特效；玩家也可手动开启。
- 音频：14 个音效（射击为魔王魂素材，其余合成）；BGM 为 HACK_NORMAL（防火墙、数据流）、HACK_BOSS（守卫程序），前奏 + 循环。
- 练习模式：不计判定，耐久归零自动恢复，开头有操作提示。
- 已部署：https://void.岸山.space/hack/ ，国内访问测试通过（2026-11-24）。

## 四、各游戏详细设计

### 1. 大楼第 50 层：全息遮蔽投影（新增设定）

**位置**：集体导入，10/15 傍晚。四人从 49 层上到 50 层，青木在对讲机里报告“敌方仿生人在向这边接近，有 4 名！”。

**设定依据**：原文中黑色装甲仿生人是“现出在你们面前”；《知识》结果“看不到编号和标记”；《计算机使用》查数据库“获取失败”。解释为它们一直被全息投影遮蔽，信号也被屏蔽。

**替换的判定**：HO2&HO4 的《计算机使用》。HO1&HO3 的《知识》保留。

**玩法（两段式）**：
1. **扫描**：50 层俯视图覆盖全息噪点，拖动扫描线显出真实画面，找出 4 个投影节点。有时间限制。
2. **关闭**：骇入找到的节点，弹幕引擎短版，每个 15–20 秒。

**参与者**：HO2、HO4 各负责两个节点，同时进行。HO1、HO3 观战，可在 QQ 报位置。四人都在场，用的是《计算机使用》，不暴露 HO4 的黑客能力。

**结果**：
- 一个都没关：原文，直接战斗。
- 关掉部分：被关的仿生人提前显形，HP -5。
- 全关：全部提前显形，HP -5。
- 全关且评价高：额外获得隐藏资料。

**隐藏资料**（所有人可见）：
1. 投影装置日志：控制信号来自识别码 **1310** 的机体。（= 佐人，屋顶跳楼的茶色头发仿生人；HO4 在第二段记忆中回收。）
2. 日志显示警方数据库的查询被这套装置主动拦截。（模糊伏笔，不提前暴露利本特。）

**定位**：玩家第一次接触骇入玩法，拘留所为正式版，难度递进。

### 1.5 HO1 梦境：组装小机器人

**位置**：搜查第一晚，HO1 的夜间单独剧情。**已定：改为晚饭前小睡**（见下方“顺序调整”）。梦里是洒满阳光的房间，HO1 抱着缺了脚的小机器人，一个男人说“给我看看”，然后问“要不要试试？”，递出机器人和工具。HO1 拧紧螺丝，男人揉揉他的头说“做得不错”。（KP 情报：小时候的 HO1 和天城。）

**原判定**：无，原文直接描写。

**玩法**：男人用手势示范下一步（指向零件、比划方向），HO1 照着把脚部零件装上、对准、拧紧螺丝。步骤 5–6 步，节奏缓慢温和，不设时限。

**线索回收**：最后一颗螺丝的形状，和 HO1 在个别导入时在地板上捡到的谜之螺丝一模一样。HO1 由此认出那是机器人的零件。
- 这同时解决了原文译者指出的冲突：导入时认出螺丝需要《机械维修》/《电子学》，但 HO1 被设定为不能使用这些技能。改为在梦里认出，不需要技能。
- **导入处同步修改**：HO1 个别导入里《侦察》找到螺丝即止，删去《机械维修》/《电子学》判定和“这是 VOID 的零件”的结果。HO1 只知道是没见过的小零件，先收着。

**顺序调整（已定：晚饭前小睡）**：
1. 赤星送 HO1 回家，开始做饭：“你先去洗澡吧。”（原文）
2. 洗完澡饭还没好。HO1 回房间躺一下，身体比想象的更疲惫，就这样睡着了。（原文睡前那句挪到这里）
3. 梦境组装小游戏。拧上最后一颗螺丝时认出它和捡到的那颗一模一样。
4. 门口传来黑田的“我回来了”，HO1 醒来。（原文从黑田进门接上）
5. 晚饭（原文）。HO1 拿出螺丝时可以直接说是机器人零件 → 黑田脸色变了，问在哪里看到的，然后先去休息。（原文）
6. 回房途中《聆听》客房里赤星的电话（原文）。之后睡下，这晚不再做梦。

**为什么不选“第二天再给黑田看”**：第二晚赤星不在家，而赤星向有马汇报“被黑田发现”的那通电话必须和黑田起疑在同一晚。挪到次日就得把电话也一起改。小睡方案只移动梦这一段，其余原文不动。

**数值**：不设失败，不挂钩技能值。

**剧透控制**：只推送给 HO1。

**素材**：可在编辑器“素材”页替换为绘制的图片（房间、男人的手、小机器人）。

### 2. 第二现场：监控录像排序（HO2 主导）

**位置**：10/16 起的自由探索，“第二起事件现场”佐久间彰人的公寓。调查完现场后，房东提出可以看监控录像。

**替换的判定**：《计算机使用》两次（发现拼接、恢复录像）。

**玩法**：录像被拆成若干段，每段带时间戳，部分时间戳被改过。玩家从光线、影子、天气等细节找出插入的别日片段，删掉后把剩下的按顺序排好。

**主导**：HO2 操作（新型机，《计算机使用》+80）。其他在场 PC 观战，可以在画面上做标记提醒 HO2。

**段数**：
- 技能高：6 段，其中 1 段假
- 技能低：8 段，其中 2 段假

**画面**：先用代码画简单像素图，之后可在编辑器“素材”页替换。

**结果**：成功 → 显示 9/2 15:00 黑兜帽人撬锁进门、十分钟后离开的画面。失败 → 只知道录像被改过。

**剧透控制**：原文此处 HO4 的秘密情报（“你可以远程黑进简单的机械里……”）只弹在 HO4 屏幕上。

### 2.5 HO3 审讯室：审问仿生人

**位置**：10/16 起的自由探索，警察厅的审讯室。审问在屋顶挟持人质的那台陷入混乱的仿生人。**前提**：它没在屋顶被破坏（原文：被破坏则没有审讯室）。

**保住前提（已定，跑屋顶时执行）**：
1. 进屋顶前，黑田在对讲机里下令：“挟持人质的那台尽量活捉，我们需要口供。”
2. 加重求饶描写：刀在发抖，一直回头看茶色头发的仿生人，反复说“我不想被废弃”。原文交涉第一回合成功就能救下人质，交涉路线本身也合理。
3. 赤星的台词改成“周围的交给我们，那台就交给你们了——它看起来是被操纵的。”
4. 兜底：玩家仍然动手时，它 HP 归 0 按“停机被捕、堆栈完好”处理，照常出现审讯室。只有玩家明确说要毁掉堆栈，才取消审讯室。

**原判定**：《交涉技能》问话。

**玩法**（纯文字，适合手机和 QQ 跑团）：
- 仿生人逐句陈述。HO3 可以对某一句“追问”，或“出示证据”指出矛盾或关联，从而解锁新话题。
- 原文的四段证词：事件那天发生了什么（茶色头发仿生人触碰它的手后系统被入侵）、关于制药公司、关于客户（白衣人，领头的黑发男人目光像蛇）、关于 EMC。

**证据来源（前后连起来）**：

| 话题 | 证据 | 在哪里拿到 |
|---|---|---|
| 事件那天发生了什么 | 不需要 | 第一段证词 |
| 关于制药公司 | 被涂黑的文件（感情抑制剂） | 49 层资料架《图书馆》。备选：搜查会议资料写明被袭击的是制药公司职员 |
| 关于客户 | 职员的记录“公司来了一群不认识的人” | 49 层书桌电脑 |
| 关于 EMC | “EMC”这个词 | 第一起事件现场客厅的小册子（《侦察》《灵感》） |

49 层调查得越全，审讯问出越多。

**兜底**：
- 49 层《图书馆》失败时，按原文探索规则让同行的赤星或黄海以 80% 重投。
- 探索顺序自由，玩家可能先来审讯室、还没去第一现场。没见过 EMC 时，“关于客户”结束后让仿生人补一句“他们的文件上印着三个字母”，追问即可解锁 EMC。

**数值挂钩**：HO3 的《交涉技能》（原文 +50）决定可以“追问”的次数和出示错误证据的容错。

**结果**：
- 问出全部证词：成功。追问次数有剩余：极限成功，KP 可追加细节。
- 只问出第一段：失败。
- 问话结束后，仿生人抬头问“我会被怎么样？”，这段保留为 RP，不做成游戏。

**参与者**：HO3 操作，同行的 PC 观战。

### 3. HO4 记忆拼图（跨夜）

**位置**：HO4 的夜间单独剧情，共三段。
1. **搜查第一晚**：理兔插入修复了一部分的堆栈。中庭，少女问 HO4 名字。
2. **搜查第二晚**（火灾那天）：心在 HO4 手背写下 00，取名“雷欧”；孩子们的数字（久绪 90、智美 3103、佐人 1310、三美 33）；孩子们开始消失。
3. **一周后 SPARROW 那晚**：警报声中，心拉着 HO4 在红光走廊里逃跑。

**原判定**：无，原文直接给出。

**玩法**：每段记忆是被打乱、带乱码的碎片，拼回顺序后解码。第二段可加机关：手背数字作为解码钥匙，与 50 层的 1310 呼应。

**图片替换**：编辑器“素材”页为每段记忆提供槽位，上传图片后选择切块数（3×3、4×4 等），系统自动切图、压缩。未上传则用文字碎片版本。

**拼完顺序**：先显示整张图，再出现记忆文字。

**数值**：不设失败，不挂钩技能值。

**剧透控制**：全部内容只推送给 HO4。

### 3.5 火灾大楼：拆除残留炸弹（非对称拆弹）

**位置**：前半所有探索结束后。黑田通知郊外发现可疑仿生人、附近大楼因爆炸起火，全员赶往现场。PC 进入着火的大楼，躲瓦砾、追褐色仿生人（大介）的途中，必经的走廊里有一个没炸的装置。

**设定依据**：KP 情报写明这场爆炸是“机构”为灭口恭和二兔设下的陷阱，大楼里留有未爆的炸弹符合设定。原文的《DEX×5》躲瓦砾、追大介、《回避》保持投骰。

**替换的判定**：HO2 或 HO4 的《计算机使用》（认出炸弹），以及拆除本身（新增）。

**玩法**：
- **HO4**（在炸弹前）：看到实物：几根不同颜色的线、显示屏图案、指示灯。
- **HO2**（远程扫描）：看到拆除手册，例如“显示屏为三角形且红线超过两根时，剪第二根红线”。
- 两人必须交流才能拆除。

**适配 QQ 打字跑团**：规则简单（三四个步骤），时限 90–120 秒；游戏内提供快捷短语按钮（如“几根红线？”“显示屏是什么图案？”），点一下即发送。

**数值挂钩**：《计算机使用》决定时限长短和手册提示的详细程度。

**结果**：
- 成功：隐藏信息——炸弹的设置时间早于大介到场，说明是专门设下的陷阱；且 HO2、HO4 记住了炸弹结构，一周后一羽拿出炸弹时的《计算机使用》自动成功。
- 失败：爆炸，附近的人受伤（数值待定），火势加快，剧情照常进入智美的战斗。

**剧透控制**：无秘密内容。

### 3.6 拘留所：黑暗潜入（非对称迷宫，新增）

**位置**：一周后 10/25 下午三点。青木切断照明，“这边已搞定，之后拜托你们了”，整栋拘留所一片漆黑。HO3、HO4 进入，要找到关押 HO1、HO2 的牢房。

**设定依据**：原文 HO4 的秘密情报中有“在看地形数据”的描写，HO4 具备获取建筑数据的能力。

**原判定**：无，属于新增环节。走到终点后接原文的警察仿生人和骇入游戏。

**玩法**：
- **HO3**：操作移动，屏幕上只有手电照亮的一小块范围。
- **HO4**：看到整栋楼的平面图、牢房位置、巡逻的警察仿生人及其视野，可以在地图上给 HO3 发箭头标记。
- 走廊里有巡逻的仿生人，被它们的视野扫到即“被发现”。

**数值挂钩**：HO3 的 DEX 决定移动速度，《侦查》决定手电范围；HO4 的《艺术（黑客）》决定地图信息是否完整（技能低时巡逻位置会延迟刷新）。

**结果**：
- 顺利到达：接原文的警察仿生人和骇入游戏。
- 被发现累计 3 次：仍然到达，但警察仿生人已进入警戒，骇入游戏难度提高一档。

**参与者与剧透控制**：只推送给 HO3、HO4 和 KP。HO4 的地图能力是否对 HO3 公开由 KP 决定。HO1、HO2 此时在牢房里，不参与。

**单机测试**：demo 阶段在一台电脑上开两个窗口，分别扮演 HO3 和 HO4。

### 4. 拘留所：骇入警察仿生人

**位置**：一周后 10/25 下午三点。HO1 被诬陷逮捕，HO2 被赤星强行带走关进同一间牢房。青木切断照明，HO3、HO4 面前出现一台警察仿生人。

**替换的判定**：HO4 的《艺术（黑客）》。

**玩法**：弹幕引擎正式版，60–90 秒，进入仿生人系统，打掉防火墙，击破核心。

**数值挂钩**：技能值决定玩家机 HP、射速、敌弹密度。

**结果**：成功 → 停机，跳过战斗。失败 → 进入原文战斗（警察仿生人 HP15），按骇入进度削减其 HP。

**剧透控制**：默认只推送给 HO4 和 KP，HO3 是否观战由 KP 决定。

### 6. 最后一天：潜行

**位置**：最后一天上午。城市被感情抑制药的粉色烟雾笼罩，有马直播宣布计划。PC 们前往利本特公司，途中躲避黑色机体仿生人。

**替换的判定**：全员《DEX×5》；HO2 或 HO4《计算机使用》成功则全员 +20%；失败者过《回避》，失败受 1d10。

**玩法**：格子移动的俯视角潜行，四人同一地图各控一个角色，移动每 0.5 秒统一结算（对延迟不敏感，手机点击/滑动操作）。HO2、HO4 可骇入街上的监控摄像头，给全队显示巡逻仿生人视野范围（对应 +20%）。

**数值挂钩**：DEX 决定移动速度；HO2/HO4 的《计算机使用》决定可骇入的摄像头数量。

**结果**：每人单独判定。被发现进入 3 秒闪避操作，失败受 1d10 伤害。

### 7. 战斗中骇入鸣宫久绪

**位置**：最后一天，利本特公司内部。挡路的是鸣宫久绪（记忆里手背写着 90 的孩子）。

**原文**：HO4 说想用黑客技能，成功则描写她的手在颤抖，技能值 -40。

**玩法**：HO4 在战斗中的一个行动，弹幕引擎短版。

## 七、角色录入界面

- 风格：HO1/HO2 为警察厅登记终端（对应导入中黑田说的“登记完成”），HO3/HO4 可为不同终端风格。
- 录入项目：姓名、HO、种类（人类/新型仿生人/旧型仿生人）、DEX、《计算机使用》《艺术（黑客）》《侦查》《机械维修》《开锁》《灵感》。
- 玩家提交后 KP 审核、修改、锁定。
- 秘密字段（如 HO4 的《艺术（黑客）》）标为仅本人和 KP 可见。

## 八、剧透控制

- 每次推送游戏时，KP 选择参与者（可操作）和观战者（只能看），其他人收不到任何通知。
- 结果在 KP 控制台显示完整内容，玩家端只显示对应部分。
- 秘密内容只在推送时由服务器发给对应玩家，不预先放在页面里（F12 看不到）。
- 玩家之间默认看不到对方数值，KP 可打开。

## 九、KP 控制台与编辑器

**控制台**：开房间、推送游戏、选择参与者/观战者、查看实时画面与进度、手动判定成功失败、接收结果（如“HO4 骇入成功，剩余 HP 3/5”）。

**编辑器四页**：
- **外观**：颜色、字体、字号、背景图、边框样式、标题文字，实时预览，可导出/导入主题文件。
- **文本**：所有游戏内文字（提示、结果描写、隐藏资料）。
- **素材**：记忆拼图、录像片段的图片槽位。
- **数值**：难度参数、HP 削减量等。

单机阶段设置保存在浏览器并可导出文件；部署后保存在服务器。

## 十、技术方案

- **形式**：网页，浏览器直接打开。
- **服务器**：现有 SillyTavern-VDS（洛杉矶，Debian 12，8 核，16G 内存，2Gbps，每月 20TB），1Panel + OpenResty，子域名 `void.岸山.space`（代号 `void.xn--rht5f.space`），经 Cloudflare 代理，证书为 Cloudflare 源站证书 `*.xn--rht5f.space`。
- **后端**：Node.js + WebSocket，房间同步。
- **网络**：HTTPS + WSS 走 443，nginx 或 Caddy 反代。
- **国内访问对策**：
  - 游戏逻辑在玩家浏览器本地运行，服务器只转发事件、结果和观战快照（约每秒 10 次），延迟不影响操作手感。
  - 不使用任何境外 CDN（Google Fonts、jsDelivr 等），全部自托管，整包控制在 1MB 以内。
  - 断线兜底：单人游戏可离线玩，结束生成带校验的结果码，玩家贴到 QQ 群，KP 在控制台验证。
  - 国内访问：2026-11-24 测试通过，打开和游玩流畅。
- **联机模式**：单人操作 + 观战（弹幕）；非对称合作；共享操作（拼图）；多人同图（潜行）。
