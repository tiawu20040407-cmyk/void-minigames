## 二、教学关卡：青木偷喝汽水

- **场景**：仿生科办公室一角，青木的工位。蕾米管青木的饮食，青木偷喝汽水，事后把那段监控剪掉，用别的日子的空工位录像补上。
- **破绽**：墙上的撕页日历。真实录像日历是 16，假片段日历是 9。日历页大、数字由游戏写上去。
- **流程**：3 段录像，1 段是假的 → 标为伪造 → 按时间排序 → 恢复：青木从抽屉里摸出一罐汽水，左右看了看，一口气喝掉半罐。
- 开始界面有“教学”和“跳过”，教学中随时可以跳过。不计错误，不算判定。KP 可设定显示或跳过。
- **锁定式指引**：每一步只有该点的地方能点。画面变暗，只亮出目标并加闪动框；点别处没反应，一羽吐槽（如“不是那里哦～看亮着的地方嘛”）。“跳过教学”一直可点。
  1. 只能点假的那段录像；
  2. 只能点墙上的日历，点了放大，一羽说“日历都对不上呢～”（教会玩家“可以点击放大”）；
  3. 只能点“标为伪造”；
  4. 排序：只能点下一个时间正确的片段；
  5. 只能点时间轴上的空缺；
  6. 恢复播放完，只能点“继续”，进入正式关卡。
- 正式关卡的大图也支持点击放大（主要为手机）。
- **教学对话（2026-11-25 用户反馈后修改）**：一羽在教学里改用屏幕下方居中的对话框（头像 + 文字），台词逐字打出；点一下打完整句，再点一下下一句，**不自动推进**。一步的台词都看完才亮出该点的目标；目标在屏幕下方时对话框自动移到上方。对话没看完时乱点只会让对话框抖一下。
- **正式关卡一羽位置**：不再贴屏幕角落，靠在内容区右下方，头像放大到 96px（手机 80px），气泡停留 8 秒。

## 三、一羽小助手

- 右下角一羽 Q 版，点一下在当前可用的台词之间轮换。标对、标错、换步骤时自动说一句。
- **设定**：这个录像分析小程序是青木写的。一羽威胁青木，不把她写进去当小助手，就告诉蕾米青木不健康饮食。没有阴谋，只是一羽爱撒娇。
- **性格**：喜欢扮可爱，想到什么说什么，略带毒舌。口癖“哦”“呢”。
- **有条件的台词**：只有这一局用了某种破绽，才会出现对应的台词。
- **图片**：256 × 256 透明 PNG，3 个表情：普通、疑惑（标错时）、开心（标对时）。占位图是一个简单的圆头小人，标“一羽”。

## 四、演出效果（科技感，保证性能）

- 调取录像：终端文字逐行打出，扫描线扫过，缩略图从马赛克色块逐张解码。
- 标对：红色扫描线、RGB 撕裂、“SPLICE DETECTED / 拼接痕迹”印章、碎成像素块消失。
- 标错：红闪、抖动、“INTEGRITY OK / 数据完整”印章。
- 排序完成：时间轴放大到空缺，红字闪烁“DATA MISSING”。
- 恢复：十六进制数据流 + 进度条；画面从大色块逐级变清晰，RGB 错位合拢；字幕逐字打出。
- 极限成功：自动框住蓝色液体，放大，标注“分析：液体 → VOID 燃料”。
- 性能：只用 2D 画布，马赛克用小图放大；特效只在一两秒内运行；卡顿自动切换简化特效，可手动开启。音效仍用代码合成，不加文件。游戏全程在玩家浏览器里运行，服务器只发一次网页。
